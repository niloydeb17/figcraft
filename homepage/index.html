A FEW THINGS TO KNOW

Before you
jump in.

Can I use Figcraft in my browser?+

Yes. Choose “Open Figcraft” to launch the existing web editor. You can also download a desktop version from the project’s GitHub releases.

Is Figcraft free and open source?+

Yes. Figcraft is available under the MIT or Apache-2.0 license. The source code, documentation, and releases are available on GitHub.

Can I open my existing design files?+

Figcraft supports its own .figcraft format, SVG, images, and best-effort .fig imports. The project is in alpha, so imported files may need adjustments. Keep a copy of your originals.

Where can I find the starter templates?+

Open the editor and select Templates on its home screen, or use File → New from template. The built-in library includes mobile, website, dashboard, design system, wireframe, social, presentation, and icon starters.
